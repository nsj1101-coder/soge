# 04. 비용 추정

## 혼자 개발하는 경우

직접 바이브 코딩으로 MVP를 만든다면 초기 비용은 낮게 가져갈 수 있습니다.

```txt
프로토타입: 0원 ~ 20만 원
내부 테스트 MVP: 20만 원 ~ 70만 원
스토어 출시 MVP: 70만 원 ~ 200만 원
본인인증/결제/운영 포함 베타: 200만 원 ~ 500만 원
```

## 기본 비용 항목

| 항목 | 예상 비용 |
|---|---:|
| Apple Developer 계정 | 연 $99 |
| Google Play 개발자 계정 | 1회 $25 |
| 도메인 | 연 1~3만 원 |
| 서버 | 초기 무료~월 5만 원 수준 가능 |
| Expo EAS Build | 무료~유료 플랜 선택 |
| 문자/휴대폰 인증 | 사용량 기반 과금 |
| 약관/개인정보처리방침 | 직접 작성 시 0원, 의뢰 시 비용 발생 |

## 비용이 커지는 지점

- 휴대폰 본인인증
- 인앱결제
- 신고/차단/운영 어드민
- 채팅 트래픽 증가
- 푸시 알림
- 앱스토어 심사 대응
- 마케팅 비용

## 외주 기준 대략 비용

```txt
디자인만 외주: 100만 ~ 300만 원
앱 MVP 개발 외주: 800만 ~ 2,000만 원
앱 + 서버 + 어드민 + 채팅 + 결제: 2,000만 ~ 5,000만 원+
운영형 소개팅 앱 구축: 5,000만 원 이상 가능
```

## 추천 전략

처음부터 큰돈을 쓰지 말고, 아래 MVP만 먼저 만듭니다.

```txt
사진 없는 가치관 프로필
가치관 매칭률
6시간 좋아요
서로 좋아요 시 채팅
백애 1송이 차감
신고/차단
```

반응이 있으면 본인인증, 결제, 추천 알고리즘, 운영 어드민을 확장합니다.
