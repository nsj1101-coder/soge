# 02. MVP 기능 정의

## MVP 목표

처음 버전은 기능을 크게 늘리지 않고, 아래 흐름만 명확하게 구현합니다.

```txt
가입 → 가치관 설문 → 추천 상대 확인 → 좋아요 → 서로 좋아요 → 채팅
```

## 핵심 기능

### 1. 회원가입 / 로그인

- 이메일 또는 휴대폰 기반 가입
- 닉네임, 성별, 나이대, 지역 입력
- 사진 업로드는 MVP에서 제외하거나 선택 기능으로 보류

### 2. 가치관 설문

예시 질문:

- 연애에서 가장 중요한 것은?
- 연락 빈도는 어느 정도가 편한가?
- 결혼에 대한 생각은?
- 주말을 보내는 방식은?
- 갈등이 생겼을 때 해결 방식은?
- 술/흡연에 대한 생각은?
- 경제관념은 어떤 편인가?

### 3. 가치관 매칭률

- 사용자 답변과 상대 답변을 비교
- 문항별 가중치를 부여할 수 있음
- 결과는 `가치관 매칭률 87%`처럼 표시

### 4. 6시간 좋아요 제한

- 사용자는 6시간에 한 번 좋아요를 보낼 수 있음
- 마지막 좋아요 발송 시간을 DB에 저장
- API 서버에서 6시간 경과 여부 검증

### 5. 서로 좋아요 시 채팅 오픈

- A가 B에게 좋아요
- B가 A에게 좋아요
- 서로 좋아요 상태가 되면 match 생성
- match가 생성된 사용자끼리만 채팅 가능

### 6. 백애 1송이 차감

정책:

- 매칭 후 채팅 중인 상태에서 새로운 매칭을 시작하려면 `백애 1송이` 차감
- 백애꽃은 앱 내 재화 또는 무료 지급 포인트로 시작 가능
- 유료 판매는 추후 인앱결제 정책 검토 후 진행

### 7. 신고 / 차단

소개팅 앱에서는 최소한 아래 기능이 필요합니다.

- 유저 차단
- 채팅 신고
- 부적절한 메시지 신고
- 관리자 확인용 어드민
