# 06. 다음 대화에서 쓸 프롬프트

VS Code에서 폴더를 만들고 다시 이어갈 때 아래처럼 요청하면 됩니다.

## 1. Expo 프로젝트 세팅 요청

```txt
백애 앱을 React Native + Expo로 만들 거야.
현재 VS Code에서 baekae 폴더를 만들었고, Expo 프로젝트 초기 세팅부터 도와줘.
온보딩, 로그인, 가치관 설문, 추천, 매칭 완료, 채팅 화면까지 라우팅 구조 먼저 잡아줘.
```

## 2. UI 먼저 만들기

```txt
백애 앱 MVP의 프론트 UI부터 만들자.
사진 없는 가치관 매칭 앱이고, 색상은 화이트/아이보리/블러쉬 핑크 계열이야.
React Native + Expo 기준으로 온보딩 화면부터 전체 코드를 줘.
```

## 3. DB 설계 요청

```txt
백애 앱 DB 설계를 해줘.
기능은 회원가입, 가치관 설문, 매칭률 계산, 6시간 좋아요, 서로 좋아요 시 채팅, 백애꽃 차감, 신고/차단이야.
MySQL 기준으로 테이블 설계와 CREATE TABLE 쿼리까지 만들어줘.
```

## 4. API 설계 요청

```txt
백애 앱 API 명세를 짜줘.
앱은 React Native + Expo, 서버는 Node.js Express, DB는 MySQL이야.
회원가입, 로그인, 가치관 저장, 추천 조회, 좋아요, 매칭 생성, 채팅 메시지 조회/전송, 백애꽃 차감 API를 설계해줘.
```

## 5. MVP 개발 순서 요청

```txt
백애 앱 MVP를 실제로 개발할 순서를 체크리스트로 짜줘.
내가 웹 개발은 할 줄 알고, React Native는 처음이야.
VS Code에서 하나씩 따라갈 수 있게 단계별로 알려줘.
```
