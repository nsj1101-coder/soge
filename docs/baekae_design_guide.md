# 백애 디자인 패턴 & 디자인 가이드

> **백애**는 사진보다 가치관을 먼저 보는 소개팅 앱입니다.  
> 디자인의 핵심은 **순수함, 신뢰감, 부드러움, 여백, 감성적인 긴장감**입니다.

---

## 1. 브랜드 컨셉

### 브랜드 키워드

| 키워드 | 설명 |
|---|---|
| 순수함 | 사진보다 마음과 가치관을 먼저 보는 서비스 철학 |
| 부드러움 | 날카로운 대비보다 은은한 색감과 둥근 형태 사용 |
| 신뢰 | 소개팅 앱 특성상 안전하고 깨끗한 인상 필요 |
| 설렘 | 매칭, 좋아요, 채팅 시작 순간에 감성적 반응 유도 |
| 절제 | 과한 장식보다 여백과 작은 꽃 포인트 중심 |

### 브랜드 한 줄 정의

```txt
백애는 얼굴보다 먼저, 마음과 가치관으로 시작하는 소개팅 앱이다.
```

### 디자인 방향

```txt
화이트 / 아이보리 배경
부드러운 핑크 포인트
꽃잎, 비단, 새틴, 흰 꽃 이미지
둥근 카드 UI
여백 많은 화면
감정적인 문구
과하지 않은 애니메이션
```

---

## 2. 전체 디자인 무드

### 메인 무드

- 깨끗한 흰색 배경
- 은은한 아이보리 톤
- 비단/새틴 같은 부드러운 천 질감
- 흰 꽃과 연핑크 꽃잎
- 투명한 카드, 부드러운 그림자
- 여성스럽지만 너무 유치하지 않은 감성

### 피해야 할 무드

- 너무 강한 레드/핫핑크
- 틴더처럼 자극적인 데이팅 앱 느낌
- 어두운 배경 위주의 섹시한 무드
- 과한 그라데이션
- 너무 많은 이모지와 장식
- 복잡한 정보 밀도

## 6. 화면별 디자인 패턴

## 6.1 인트로 / 온보딩 화면

### 목적

- 브랜드 첫인상 전달
- “사진보다 마음이 먼저”라는 철학 각인
- 진입 버튼 제공

### 구성

```txt
배경: 새틴/비단 질감 + 흰 꽃 + 꽃잎
중앙 상단: 꽃 로고
중앙: 백애 로고 텍스트
중앙 하단: 슬로건
하단: 백애 시작하기 버튼
버튼 아래: 로그인 링크
```

### 문구 예시

```txt
백애
사진보다 마음이 먼저,
가치관으로 시작하는 사랑

[백애 시작하기]
이미 계정이 있으신가요? 로그인
```

### 디자인 포인트

- 배경 이미지는 매우 연하게 처리
- 텍스트 주변은 충분히 비워둠
- 로고는 꽃 아이콘 + 한글 로고 조합
- 버튼은 화면 하단에서 안정적으로 배치

---

## 6.2 가치관 프로필 화면

### 목적

- 사용자의 연애/생활 가치관 수집
- 매칭률 계산을 위한 데이터 확보
- 설문이 부담스럽지 않도록 카드형 UI 사용

### 구성

```txt
상단: 뒤로가기 / 제목 / 진행률
본문: 질문 안내 문구
질문 카드 리스트
하단: 다음 버튼
```

### 질문 카드 패턴

```txt
[아이콘] 연애에서 중요한 것
[신뢰] [대화] [가치관] [설렘] [성장]
```

### 설문 카테고리 예시

| 카테고리 | 선택지 예시 |
|---|---|
| 연애에서 중요한 것 | 신뢰, 대화, 가치관, 설렘, 성장 |
| 결혼에 대한 생각 | 언젠가는 하고 싶어요, 당장은 아니에요, 잘 모르겠어요 |
| 연락 빈도 | 하루 1~2번, 항상 가능, 적당히, 자유롭게 |
| 주말을 보내는 방식 | 집에서 휴식, 취미 활동, 나들이, 모임/약속 |
| 갈등 해결 방식 | 바로 대화, 시간 필요, 글로 정리, 감정 진정 후 대화 |

### 디자인 포인트

- 선택된 태그는 Soft Pink 배경
- 진행률은 상단에 얇게 표시
- 질문 카드 간 여백을 충분히 줌
- 너무 많은 선택지를 한 화면에 넣지 않기

## 6.3 오늘의 추천 화면

### 목적

- 6시간마다 추천된 상대 노출
- 사진 없이도 상대의 분위기와 가치관을 이해하게 함
- 매칭률을 강하게 보여줌

### 구성

```txt
상단: 오늘의 추천 / 알림 아이콘
쿨타임 안내: 좋아요는 6시간마다 보낼 수 있어요
상대 카드
하단 액션: X / 좋아요 보내기 / 저장
하단 탭 메뉴
```

### 상대 카드 구성

```txt
원형 이니셜 아바타
나이대 / 지역
직업군 / 관심사
가치관 요약 태그
매칭률
```

### 예시

```txt
S
27 ~ 32세 · 서울
회사원 · 마케팅
#책읽기 #여행 #요리 #필라테스

차분함 / 성실 / 대화 중시
결혼은 천천히 / 가족 중심 / 서로 존중

가치관 매칭률 87%
```

### 디자인 포인트

- 프로필 사진 대신 이니셜 원형 아바타 사용
- 매칭률 87%는 화면에서 가장 강한 시각 요소
- 좋아요 버튼은 꽃 아이콘과 함께 사용
- 추천 화면은 전체적으로 카드 중심 구조

## 6.4 매칭 완료 화면

### 목적

- 서로 좋아요 성공을 감성적으로 표현
- 채팅 시작 유도
- 백애꽃 차감 정책 안내

### 구성

```txt
상단: 뒤로가기
중앙: 매칭 완료 문구
두 사람 이니셜 + 하트/꽃 애니메이션
안내 카드
보유 백애꽃 카드
하단 CTA: 채팅하러 가기
```

### 문구 예시

```txt
서로의 마음이 닿았어요
축하해요! 새로운 인연이 시작될 수 있어요.

서로 좋아요 시
채팅 시작
서로의 마음이 확인되면 채팅으로 이어질 수 있어요.

채팅 중 새로운 매칭 시작 시
백애 1송이 차감
더 진심 어린 만남을 위해 백애꽃이 사용돼요.
```

### 디자인 포인트

- 매칭 순간은 앱의 감정적 피크
- 작은 하트/꽃잎 애니메이션 사용 가능
- 정보는 카드 안에 부드럽게 정리
- 하단 버튼은 명확하게 배치

---

## 6.5 채팅 화면

### 목적

- 매칭된 사람과 대화
- 매칭률과 백애꽃 보유량 확인
- 새로운 매칭 시작 시 백애꽃 차감 안내

### 구성

```txt
상단: 뒤로가기 / 채팅 / 더보기
상대 정보: 이니셜, 매칭률, 보유 백애꽃
안내 배너
채팅 메시지 리스트
하단 입력창
```

### 채팅 말풍선

| 타입 | 배경 | 위치 |
|---|---|---|
| 상대 메시지 | `#F1EDEA` | 왼쪽 |
| 내 메시지 | `#F7DDE2` | 오른쪽 |
| 시스템 안내 | `#FFF1E3` | 중앙 또는 상단 |

### 메시지 예시

```txt
상대: 안녕하세요! 좋은 아침이에요 ☀️
나: 안녕하세요! 맞아요 :) 기분 좋은 하루 보내고 계신가요?
상대: 네! 운동하고 책도 읽었어요.
나: 저는 주말에 주로 카페 가거나 필라테스를 해요 ☕
```

### 디자인 포인트

- 채팅 배경은 완전 흰색보다 아주 연한 핑크/아이보리
- 말풍선은 둥글게, 꼬리는 작게
- 메시지 텍스트는 가독성이 가장 중요
- 매칭률 87%는 상단에서 작게 강조

## 9. 이미지/그래픽 가이드

### 배경 이미지

추천 요소:

```txt
흰 새틴 천
은은한 옷 구김/천 주름
흰 꽃
연핑크 꽃잎
부드러운 빛 번짐
```

사용 기준:

```txt
인트로: 배경 이미지 사용 가능
일반 화면: 거의 흰색 배경 + 아주 약한 플로럴 장식
채팅: 배경 장식 최소화
추천 화면: 카드 뒤쪽에 연한 블러 배경 가능
```

### 배경 투명도

```txt
인트로 배경: 100%
일반 화면 장식: 10~25%
카드 내부 장식: 5~15%
```

## 10. UX 패턴

## 10.1 6시간 좋아요 제한

### 기본 정책

```txt
좋아요는 6시간마다 1번 보낼 수 있다.
서로 좋아요를 보내면 매칭된다.
매칭되면 채팅이 열린다.
채팅 중 새로운 매칭을 시작하려면 백애꽃 1송이가 차감된다.
```

### 화면 표현

```txt
좋아요는 6시간마다 보낼 수 있어요
05:23:41 남음
```

### 버튼 상태

| 상태 | 표현 |
|---|---|
| 가능 | 좋아요 보내기 버튼 활성화 |
| 쿨타임 | 남은 시간 표시, 버튼 비활성화 |
| 매칭 성공 | 매칭 완료 화면 이동 |
| 백애꽃 부족 | 충전/획득 안내 |

## 10.2 매칭률 표시

### 표현 방식

```txt
가치관 매칭률 87%
```

### 색상 기준

| 매칭률 | 색상 | 설명 |
|---:|---|---|
| 80~100% | `#D96B7C` | 높은 매칭 |
| 60~79% | `#E6A15D` | 보통 이상 |
| 40~59% | `#999999` | 보통 |
| 0~39% | `#B8B8B8` | 낮음 |

## 12. 애니메이션 가이드

### 사용 가능한 애니메이션

| 위치 | 애니메이션 |
|---|---|
| 인트로 | 꽃잎이 천천히 떠오름 |
| 좋아요 클릭 | 하트/꽃잎이 작게 터짐 |
| 매칭 성공 | 두 이니셜 사이 하트 등장 |
| 버튼 클릭 | scale 0.98 후 복귀 |
| 카드 전환 | 좌우 슬라이드 |
| 채팅 메시지 | 아래에서 부드럽게 등장 |

### 애니메이션 원칙

```txt
속도는 느리고 부드럽게
과한 bounce 금지
감성적이지만 앱 사용을 방해하지 않게
```

### 권장 값

```txt
Duration: 180~320ms
Easing: ease-out / ease-in-out
Scale Press: 0.97~0.98
Card Transition: 240ms
```

## 13. 접근성/가독성 기준

### 최소 기준

```txt
본문 텍스트 14px 이상
버튼 높이 48px 이상
터치 영역 44px 이상
중요 텍스트와 배경 대비 확보
핑크 텍스트는 너무 연하게 사용하지 않기
```

### 주의할 점

- 연핑크 배경 위에 연핑크 텍스트 금지
- 작은 회색 텍스트 남발 금지
- 채팅 말풍선 안의 텍스트는 무조건 진한 색 사용
- 버튼 비활성 상태도 의미가 구분되어야 함
